# 🎯 Elevator System Design

Design an **Object-Oriented Elevator System** for a multi-floor building that efficiently handles passenger requests, manages multiple elevators, and optimizes wait times.

> **Real-world analogy:** A real elevator system in a 20-story office building — passengers press buttons, the system dispatches the nearest elevator, handles multiple concurrent requests, and each car tracks its own direction and queue.

---

## 📋 Requirements

### Functional
- Support multiple elevators in a building
- Handle both external (floor button) and internal (car button) requests
- Move elevators up/down, open/close doors
- Display current floor and direction
- Dispatch the optimal elevator for each request

### Non-Functional
- Minimize average wait time
- Thread-safe for concurrent requests
- Handle edge cases (overweight, door obstruction)

---

## 🔍 Class Design

| Class | Responsibility |
|-------|---------------|
| `ElevatorSystem` | Manages all elevators and dispatching |
| `Elevator` | Single elevator car with state, direction, queue |
| `Request` | Represents a floor request (internal or external) |
| `Direction` | Enum: UP, DOWN, IDLE |
| `Dispatcher` | Strategy for choosing which elevator to send |

    DOWN = -1

class Elevator:
    def __init__(self, elevator_id: int, max_floor: int):
        self.id = elevator_id
        self.current_floor = 1
        self.direction = Direction.IDLE
        self.max_floor = max_floor
        self._up_stops: set[int] = set()
        self._down_stops: set[int] = set()
        self._lock = threading.Lock()

    def add_request(self, floor: int):
        with self._lock:
            if floor > self.current_floor:
                self._up_stops.add(floor)
            elif floor < self.current_floor:
                self._down_stops.add(floor)
            # Same floor — open doors immediately

    def step(self) -> str | None:
        """Move one floor in current direction. Returns action."""
        with self._lock:
            if self.direction == Direction.UP:
                if self.current_floor in self._up_stops:
                    self._up_stops.discard(self.current_floor)
                    return f"Elevator {self.id}: STOP at floor {self.current_floor}"
                if self._up_stops:
                    self.current_floor += 1
                else:
                    self.direction = Direction.DOWN if self._down_stops else Direction.IDLE

            elif self.direction == Direction.DOWN:
                if self.current_floor in self._down_stops:
                    self._down_stops.discard(self.current_floor)
                    return f"Elevator {self.id}: STOP at floor {self.current_floor}"
                if self._down_stops:
                    self.current_floor -= 1
                else:
                    self.direction = Direction.UP if self._up_stops else Direction.IDLE

            elif self.direction == Direction.IDLE:
                if self._up_stops:
                    self.direction = Direction.UP
                elif self._down_stops:
                    self.direction = Direction.DOWN

            return None

    @property
    def is_idle(self) -> bool:
        return (self.direction == Direction.IDLE
                and not self._up_stops and not self._down_stops)

    def distance_to(self, floor: int) -> int:
        return abs(self.current_floor - floor)

class ElevatorSystem:
    def __init__(self, num_elevators: int, num_floors: int):
        self.elevators = [
            Elevator(i + 1, num_floors)
            for i in range(num_elevators)
        ]
        self.num_floors = num_floors

    def request_elevator(self, floor: int,
                         direction: Direction = Direction.UP):
        """Dispatch nearest suitable elevator."""
        best = min(self.elevators, key=lambda e: (
            0 if e.is_idle else 1,  # Prefer idle
            e.distance_to(floor),    # Then nearest
        ))
        best.add_request(floor)
        if best.is_idle:
            if floor > best.current_floor:
                best.direction = Direction.UP
            elif floor < best.current_floor:
                best.direction = Direction.DOWN
        print(f"📍 Floor {floor} → Elevator {best.id}"
              f" (at floor {best.current_floor})")

    def press_floor_button(self, elevator_id: int, floor: int):
        """Passenger inside elevator presses a floor button."""
        elevator = self.elevators[elevator_id - 1]
        elevator.add_request(floor)

    def simulate_step(self):
        for elevator in self.elevators:
            action = elevator.step()
            if action:
                print(action)

system.request_elevator(12, Direction.DOWN)

    private final int id;
    private int currentFloor = 1;
    private Direction direction = Direction.IDLE;
    private final TreeSet<Integer> upStops = new TreeSet<>();
    private final TreeSet<Integer> downStops = new TreeSet<>();
    private final ReentrantLock lock = new ReentrantLock();

    public void addRequest(int floor) {

        try {
            if (floor > currentFloor) upStops.add(floor);
            else if (floor < currentFloor) downStops.add(floor);
        } finally {
            lock.unlock();
        }
    }

    public void step() {

        try {

                upStops.remove(currentFloor);
                System.out.printf("Elevator %d: STOP floor %d%n",

            } else if (direction == Direction.UP && !upStops.isEmpty()) {
                currentFloor++;
            } else if (direction == Direction.DOWN
                    && downStops.contains(currentFloor)) {
                downStops.remove(currentFloor);
            } else if (direction == Direction.DOWN
                    && !downStops.isEmpty()) {
                currentFloor--;

                direction = !upStops.isEmpty() ? Direction.UP
                    : !downStops.isEmpty() ? Direction.DOWN
                    : Direction.IDLE;
            }
        } finally {
            lock.unlock();
        }
    }

    public int distanceTo(int floor) {
        return Math.abs(currentFloor - floor);
    }

    public boolean isIdle() {
        return direction == Direction.IDLE
            && upStops.isEmpty() && downStops.isEmpty();

## 📊 Dispatching Algorithms

| Algorithm | How It Works | Efficiency |
|-----------|-------------|------------|
| **FCFS** | First come first served | Fair but slow |
| **SCAN (Elevator)** | Go up, then down, servicing requests | Good for uniform traffic |
| **LOOK** | Like SCAN but reverses at last request | Better than SCAN |
| **Nearest Car** | Send closest idle/same-direction car | Best for low traffic |

## 📝 Quick Quiz

**Q1: Elevator 1 is on floor 3 going UP. Elevator 2 is on floor 8, IDLE. A request comes from floor 6 going UP. Which elevator should respond?**

A) Elevator 1 (same direction)  B) Elevator 2 (closer)

**Answer: A** — Elevator 1 is going UP and will pass floor 6. Elevator 2 is closer but idle. The SCAN algorithm prefers servicing requests in the current travel direction to avoid unnecessary direction changes.
