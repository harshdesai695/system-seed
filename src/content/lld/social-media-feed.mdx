# 🎯 Social Media Feed Design

Design an **Object-Oriented Social Media Feed System** that supports creating posts, following users, generating personalized feeds, and handling interactions (likes, comments).

<Callout type="tip" title="Real-World Analogy">
  Instagram or Twitter — you follow people, their posts appear in your feed sorted by time or relevance, and you can like, comment, and share.
</Callout>

---

## 📋 Requirements

### Functional
- Users can create text/image posts
- Follow/unfollow other users
- Generate a personalized news feed (posts from followed users)
- Like and comment on posts
- Feed pagination (load more)

---

## 🔍 Feed Generation Strategies

| Strategy | How It Works | Pros | Cons |
|----------|-------------|------|------|
| **Pull (Fan-out on read)** | Fetch posts from followed users at query time | Simple, fresh data | Slow for users following many people |
| **Push (Fan-out on write)** | Pre-compute feed when a post is created | Fast reads | Expensive for celebrities (many followers) |
| **Hybrid** | Push for normal users, pull for celebrities | Balanced | Complex |

    def __init__(self):
        self._users: dict[str, User] = {}
        self._posts: dict[str, Post] = {}
        self._user_posts: dict[str, list[str]] = defaultdict(list)
        self._feed_cache: dict[str, list[str]] = defaultdict(list)
        self._counter = 0

    def register_user(self, user_id: str, username: str) -> User:
        user = User(user_id, username)
        self._users[user_id] = user
        return user

    def create_post(self, author_id: str, content: str) -> Post:
        self._counter += 1
        post_id = f"P-{self._counter:06d}"
        post = Post(post_id, author_id, content)
        self._posts[post_id] = post
        self._user_posts[author_id].append(post_id)

        # Fan-out on write: push to followers' feeds
        author = self._users[author_id]
        for follower_id in author.followers:
            self._feed_cache[follower_id].insert(0, post_id)
            # Keep feed cache bounded
            self._feed_cache[follower_id] = \
                self._feed_cache[follower_id][:200]

        return post

    def get_feed(self, user_id: str, page: int = 0,
                 page_size: int = 10) -> list[Post]:
        """Get personalized feed for a user."""
        # Try cache first (fan-out on write)
        cached = self._feed_cache.get(user_id, [])
        if cached:
            start = page * page_size
            end = start + page_size
            post_ids = cached[start:end]
            return [self._posts[pid] for pid in post_ids
                    if pid in self._posts]

        # Fallback: fan-out on read
        user = self._users.get(user_id)
        if not user:
            return []

        all_posts = []
        for followed_id in user.following:
            for post_id in self._user_posts.get(followed_id, []):
                all_posts.append(self._posts[post_id])

        all_posts.sort(key=lambda p: p.created_at, reverse=True)
        start = page * page_size
        return all_posts[start:start + page_size]

    def like_post(self, user_id: str, post_id: str):
        post = self._posts.get(post_id)
        if post:
            post.like(user_id)

    def comment_on_post(self, user_id: str, post_id: str,
                        text: str):
        post = self._posts.get(post_id)
        if post:
            post.add_comment(user_id, text)

    private final Map<String, User> users = new ConcurrentHashMap<>();
    private final Map<String, Post> posts = new ConcurrentHashMap<>();
    private final Map<String, List<String>> userPosts
        = new ConcurrentHashMap<>();
    private final Map<String, LinkedList<String>> feedCache
        = new ConcurrentHashMap<>();
    private final AtomicInteger counter = new AtomicInteger(0);

    public Post createPost(String authorId, String content) {
        String postId = "P-" + counter.incrementAndGet();
        Post post = new Post(postId, authorId, content);
        posts.put(postId, post);
        userPosts.computeIfAbsent(authorId,
            k -> new ArrayList<>()).add(postId);

        // Fan-out on write
        User author = users.get(authorId);
        for (String followerId : author.getFollowers()) {
            feedCache.computeIfAbsent(followerId,
                k -> new LinkedList<>()).addFirst(postId);
        }
        return post;
    }

    public List<Post> getFeed(String userId, int page,
                              int pageSize) {
        var cached = feedCache.getOrDefault(userId, new LinkedList<>());
        int start = page * pageSize;
        int end = Math.min(start + pageSize, cached.size());
        if (start >= cached.size()) return List.of();

        return cached.subList(start, end).stream()
            .map(posts::get)
            .filter(Objects::nonNull)
            .toList();

    defer fs.mu.RUnlock()

    cached := fs.feedCache[userID]
    start := page * size
    end := start + size
    if start >= len(cached) { return nil }
    if end > len(cached) { end = len(cached) }

    var result []*Post

        }
    }

## 📝 Quick Quiz

**Q1: A celebrity with 10 million followers creates a post. Using fan-out on write, what problem occurs?**

A) No problem  B) Writing to 10 million feed caches is extremely slow

**Answer: B** — Fan-out on write means inserting the post ID into 10 million users' feed caches. This is slow and expensive. For celebrities, use fan-out on read (pull model) instead — a hybrid approach.
