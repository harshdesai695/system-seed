# 🎯 What is DNS?

**DNS (Domain Name System)** is the internet's phone book. It translates human-readable domain names (like `google.com`) into IP addresses (like `142.250.80.46`) that computers use to identify each other.

<Callout type="tip" title="Real-World Analogy">
  You don't memorize your friends' phone numbers — you save them under names in your **contacts app**. When you tap "Mom," your phone looks up her number and calls it. DNS works the same way: you type `google.com`, DNS looks up `142.250.80.46`, and your browser connects.
</Callout>

---

## 🌍 Real-World Example

Every time you visit a website, DNS is at work. **Cloudflare's 1.1.1.1** and **Google's 8.8.8.8** are public DNS resolvers that handle billions of DNS queries daily, translating domain names to IP addresses for users worldwide.

---

## 🔍 How DNS Resolution Works (Step by Step)

1. You type `www.example.com` in your browser
2. **Browser cache** — Already know the IP? Use it! ✅
3. **OS cache** — Check the local operating system cache
4. **Recursive resolver** — Your ISP's DNS server (or 8.8.8.8)
5. **Root nameserver** — "I don't know example.com, but ask the `.com` server"
6. **TLD nameserver** — ".com server says: example.com is managed by `ns1.example.com`"
7. **Authoritative nameserver** — "example.com → 93.184.216.34" ✅
8. IP returned to browser → connection established

---

## 📊 DNS Record Types

| Record | Purpose | Example |
|--------|---------|---------|
| **A** | Maps domain to IPv4 | `example.com → 93.184.216.34` |
| **AAAA** | Maps domain to IPv6 | `example.com → 2606:2800:220:1::248` |
| **CNAME** | Alias one domain to another | `www.example.com → example.com` |
| **MX** | Mail server routing | `example.com → mail.example.com` |
| **NS** | Nameserver delegation | `example.com → ns1.example.com` |
| **TXT** | Arbitrary text (verification) | SPF, DKIM email validation |
| **TTL** | Time to live (cache duration) | `300` (5 minutes) |

def dns_lookup(domain: str):

        ip = socket.gethostbyname(domain)

        return ip

        print(f"DNS lookup failed for {domain}")

# Get all IPs (load balanced domains have multiple)
def dns_lookup_all(domain: str):
    try:
        results = socket.getaddrinfo(domain, 80)
        ips = set(r[4][0] for r in results)
        for ip in ips:
            print(f"{domain} → {ip}")
        return list(ips)
    except socket.gaierror:

public class DnsLookup {
    public static void lookup(String domain) {
        try {
            // Single lookup
            InetAddress addr = InetAddress.getByName(domain);
            System.out.println(domain + " → " + addr.getHostAddress());

                System.out.println("  IP: " + a.getHostAddress());
            }

    }

void dnsLookup(const std::string& domain) {

## ⚖️ Pros & Cons

| Pros ✅ | Cons ❌ |
|---------|---------|
| Human-readable addresses | DNS propagation delays |
| Load distribution via multiple IPs | DNS spoofing/cache poisoning risks |
| Caching reduces latency | Single point of failure without redundancy |

## 📝 Quick Quiz

**Q1: You update your website's server IP. Users still see the old site for hours. Why?**

A) The server didn't restart  B) DNS caches still hold the old IP (TTL hasn't expired)

**Answer: B** — DNS records have a TTL (Time to Live). Until the cached record expires, resolvers return the old IP.
