# 🎯 What is a CDN?

**CDN (Content Delivery Network)** is a geographically distributed network of servers that delivers web content to users from the server closest to them, reducing latency.

<Callout type="tip" title="Real-World Analogy">
  Imagine a global bookstore chain. Instead of shipping every book from a central warehouse in New York, they stock popular titles at **local stores worldwide**. When you want a bestseller in Tokyo, you get it from the Tokyo store instantly instead of waiting for a shipment from New York.
</Callout>

---

## 🌍 Real-World Example

**Netflix** uses its own CDN called **Open Connect**. Netflix pre-positions popular movies and shows on servers inside ISP networks around the world. When you stream a show, the data comes from a server just a few miles away, not from Netflix's main data centers.

---

## 🔍 How Does It Work?

1. **User** requests content (e.g., an image, video, CSS file)
2. **DNS** resolves the domain to the nearest CDN **edge server**
3. **Edge server** checks if it has the content cached
4. **Cache hit**: Content returned immediately (fast!)
5. **Cache miss**: Edge server fetches from the **origin server**, caches it, then returns it

### CDN Architecture

| Component | Role |
|-----------|------|
| **Origin Server** | The original source of content |
| **Edge Servers** | Distributed servers close to users |
| **PoPs** (Points of Presence) | Data center locations of edge servers |
| **DNS** | Routes users to nearest edge server |

---

## 📊 What CDNs Cache

| Content Type | Example | CDN Effectiveness |
|:---|:---|:---:|
| Static assets | Images, CSS, JS, fonts | Excellent |
| Video content | Streaming media | Excellent |
| API responses | Cacheable GET responses | Good |
| Dynamic content | Personalized pages | Limited |


---

## ⚖️ Pros & Cons

| Pros ✅ | Cons ❌ |
|---------|---------|
| Reduced latency | Stale content risk |
| Lower origin server load | Cost (bandwidth fees) |
| DDoS protection | Cache invalidation complexity |
| Global availability | Not suitable for all content types |

---

## 🧩 When to Use

- **Always** for static assets (images, CSS, JS, fonts, videos)
- **Often** for cacheable API responses
- **Carefully** for personalized or real-time content

## 📝 Quick Quiz

**Q1: Your website serves the same product images to millions of users. Where should these images be served from?**

A) The origin server directly  B) A CDN edge server near the user

**Answer: B** — CDN edge servers drastically reduce latency and offload traffic from the origin.
