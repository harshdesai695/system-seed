# 🎯 What is a Heartbeat?

A **heartbeat** is a periodic signal sent between nodes in a distributed system to indicate they are alive and functioning. If a node stops sending heartbeats, other nodes consider it failed and take corrective action.

> **Real-world analogy:** A **night security guard** checks in every 30 minutes by walkie-talkie. If they miss two consecutive check-ins, the control room assumes something is wrong and sends a replacement. That's exactly how heartbeats work in distributed systems.

---

## 🌍 Real-World Example

**Kubernetes** uses heartbeats (called "node status updates") to monitor cluster health. Each node's **kubelet** sends heartbeat signals to the API server every 10 seconds. If the API server doesn't receive a heartbeat for 40 seconds, the node is marked `NotReady` and its pods are rescheduled.

---

## 🔍 How Heartbeats Work

1. **Node A** sends a heartbeat to the **monitor** every `T` seconds
2. Monitor tracks the **last heartbeat timestamp** for each node
3. If no heartbeat is received within `timeout` (usually 2–3× interval), the node is marked **suspect**
4. After a **grace period**, the node is declared **dead**
5. System triggers **failover** — reassigns work, promotes replicas, alerts operators

---

## 📊 Heartbeat Strategies

| Strategy | How It Works | Use Case |
|----------|-------------|----------|
| **Push** | Node sends periodic "I'm alive" messages | Kubernetes, ZooKeeper |
| **Pull** | Monitor pings nodes and expects response | Load balancer health checks |
| **Gossip** | Nodes share heartbeat info with each other | Cassandra, DynamoDB |
| **Lease-based** | Node holds a lease; must renew before expiry | Chubby, etcd leader election |

import threading
from typing import Dict

class HeartbeatMonitor:
    def __init__(self, timeout: float = 10.0):
        self.timeout = timeout
        self.heartbeats: Dict[str, float] = {}
        self.lock = threading.Lock()
        self._running = True

    def receive_heartbeat(self, node_id: str):
        with self.lock:
            self.heartbeats[node_id] = time.time()
            print(f"♥ Heartbeat from {node_id}")

    def check_health(self) -> dict:
        now = time.time()
        status = {}
        with self.lock:
            for node_id, last_beat in self.heartbeats.items():
                elapsed = now - last_beat
                if elapsed < self.timeout:
                    status[node_id] = "HEALTHY"
                elif elapsed < self.timeout * 2:
                    status[node_id] = "SUSPECT"
                else:
                    status[node_id] = "DEAD"
        return status

    def start_monitoring(self, interval: float = 5.0):
        def monitor_loop():
            while self._running:
                health = self.check_health()
                for node, state in health.items():
                    if state != "HEALTHY":
                        print(f"⚠ {node}: {state}")
                time.sleep(interval)
        thread = threading.Thread(target=monitor_loop, daemon=True)
        thread.start()

| Works at any scale | Tuning timeouts is tricky |

## 📝 Quick Quiz

**Q1: Your heartbeat timeout is 5s, but network latency spikes to 6s occasionally. What happens?**

A) Nothing, the system adjusts  B) Healthy nodes are falsely marked dead

**Answer: B** — If latency exceeds the timeout, perfectly healthy nodes will be incorrectly marked as failed. Use a higher timeout or implement a "suspect" state with retries.
