# 🎯 What is a Checksum?

A **checksum** is a small fixed-size value derived from a block of data, used to detect errors or corruption during transmission or storage. If the data changes even slightly, the checksum changes dramatically.

<Callout type="tip" title="Real-World Analogy">
  Imagine mailing a 100-page manuscript. You write "Total words: 23,847" on the envelope. When the recipient counts the words and gets 23,847, they know the manuscript arrived intact. If the count is different, something was lost or changed. That number is a checksum.
</Callout>

---

## 🌍 Real-World Example

**Amazon S3** uses MD5 checksums for every object uploaded. When you upload a file, S3 computes an MD5 hash and compares it with the one you sent. If they don't match, the upload is rejected, preventing corrupted data from being stored.

---

## 🔍 How Checksums Work

1. **Sender** computes checksum of original data using a hash function
2. **Sends** data + checksum to recipient
3. **Recipient** computes checksum of received data using the same function
4. **Compares** — if checksums match, data is intact ✅; if not, data is corrupt ❌

---

## 📊 Common Checksum Algorithms

| Algorithm | Output Size | Speed | Collision Resistance | Use Case |
|-----------|------------|-------|---------------------|----------|
| **CRC32** | 32 bits | Very Fast | Low | Network packets, ZIP files |
| **MD5** | 128 bits | Fast | Broken (not secure) | File verification |
| **SHA-1** | 160 bits | Fast | Broken (not secure) | Git commits |
| **SHA-256** | 256 bits | Moderate | Strong | Blockchain, TLS |
| **xxHash** | 64/128 bits | Extremely Fast | Moderate | Database checksums |


---

## ⚖️ Pros & Cons

| Pros ✅ | Cons ❌ |
|---------|---------|
| Detects data corruption | Cannot repair data |
| Fast to compute | Hash collisions possible (rare) |
| Small overhead | Adds processing time |

## 📝 Quick Quiz

**Q1: You download a 2GB file whose published SHA-256 hash is `abc123...`. Your computed hash is `def456...`. What happened?**

A) Nothing, hashes can differ  B) The file was corrupted or tampered with during download

**Answer: B** — A different checksum means the file's content changed. Re-download and verify again.
